# Floor 13 - Chapter 2 Google Flow Comic Prompts

Chapter 2 title: **Ghar Chhod Do**

Use these prompts for Google Flow comic-page image generation after Page 25. This chapter continues from the cliffhanger where the phone audio says "Ghar chhod do" in Arjun's own voice.

## Common Prompt Header

Paste this before each page prompt:

```text
Create one full comic book page in a clean modern graphic-novel style, thick black panel borders, white page margin, flat colors, clean ink lines, expressive faces, readable speech bubbles, printed comic-page look.

IMPORTANT TEXT RULES:
Write only the exact dialogue text provided below.
Use clean, readable, bold comic lettering.
Do not add extra words, random letters, captions, labels, sound effects, or watermarks.
Keep all speech bubble text inside the bubbles.
Use Roman Hindi-English exactly as written.

Use the uploaded character sheets as exact references. Keep faces, hairstyles, outfits, body types, colors, and proportions consistent across all panels.
Use uploaded background/location sheets as exact references for architecture, furniture placement, colors, and mood.
The Fifth Shadow must stay faceless, vague, human-like, and made of smoky darkness. Never reveal a monster face.

Negative prompt: photorealistic, 3D render, anime, manga, superhero style, gore, demon, monster, clear ghost face, misspelled text, random letters, extra words, distorted bubbles, unreadable text, extra fingers, broken hands, inconsistent faces, inconsistent outfits, western house, fantasy setting, blurry image, messy panel layout.
```
