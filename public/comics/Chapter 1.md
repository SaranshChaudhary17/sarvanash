# Floor 13 - Google Flow Comic Page Prompts

Use these prompts to generate **comic page images**, not videos. Each prompt should create one full comic page with multiple panels, thick black borders, flat colors, speech bubbles, and a clean graphic-novel layout.

## Global Style Prompt

Paste this at the start of every page prompt, or keep it as your project style:

```text
Create one full comic book page in a clean modern graphic-novel style, similar to a flat-color indie comic page: thick black panel borders, white page margin, expressive simplified characters, clean ink lines, warm muted colors, readable speech bubbles, dramatic but simple backgrounds, cinematic horror-comedy mood, no realistic photo style, no 3D render, no anime, no manga, no gore. The page should look like a printed comic page with 4 to 6 panels arranged clearly.
```
